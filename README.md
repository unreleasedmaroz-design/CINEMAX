# Cinema IMAX — GitHub Pages

Upload the contents of this folder to the repository root.

Structure:

- `index.html` — main website
- `player/index.html` — player page
- `404.html` — GitHub Pages fallback for `/player/{tmdb_id}`

The Watch buttons navigate to:

`/player/{tmdb_id}`

Example:

`https://USERNAME.github.io/REPOSITORY/player/1078605`

Enable GitHub Pages from Settings → Pages → Deploy from a branch.
